# Myriad OS

Myriad OS is an original operating system and the central project of the Myriad OS ecosystem. This repository is dedicated exclusively to the operating system, including user-space components, system services, utilities, user interface, and system integration.

Myriad OS is designed to integrate with Menagerie Kernel and support software written in Orum through clearly defined interfaces, while maintaining independent development and version control.

## Related projects

- [Menagerie Kernel](https://github.com/Redcherryman/Menagerie-Kernel) — the kernel
- [Orum](https://github.com/Redcherryman/Orum) — the ecosystem programming language
